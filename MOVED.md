# Where did my folder go?

On 2026-09-19 this repo moved its 70 top-level project folders into six top-level folders (`frameworks/`, `mini_projects/`, `integrations/`, `tools/`, `youtube_shorts/`, `claude_skill_agent_builder/`). Links from older videos and blog posts that point at `tylerprogramming/ai/tree/main/<old_folder>` now return 404.

Find the old folder name below and open the new path. Most folders kept their inner layout. Local config files (`.env`, `OAI_CONFIG_LIST`), IDE folders and a few obsolete scripts were not carried over. Many projects were also updated for current framework versions (see the main [README](README.md#framework-versions-october-2026)), so code can differ from the video.
