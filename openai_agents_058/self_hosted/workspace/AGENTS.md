# Notes folder

This is a personal notes folder. Every file is markdown.

- `todo.md` is the to-do list. New items go at the bottom as `- [ ] item`.
  Done items get `- [x]`. Never delete a line, only check it off.
- `groceries.md` is a flat list. One item per line, lowercase.
- `meeting-*.md` are meeting notes. Do not edit past meetings.
- `idea-*.md` are rough ideas. Adding to them is fine.
- Do not create files outside this folder. Do not delete files.
- When asked a question about the notes, read the files first. Keep answers short.
