# **Create and Edit Software**

> **Note:** Updated to AutoGen v0.7. The original video used the older AutoGen 0.2 API, so the code here differs from what's on screen.

I think a realistic version of an AI Engineer is to also allow it to edit already existing code.  You won't always be creating new code the way you want, and you will probably have to adhere to how existing code is written.

## Run it:
- `pip install -r requirements.txt`
- Put `OPENAI_API_KEY` in a `.env` file
- `python main.py` (you are the Admin: type instructions for the Engineer, or `exit` to stop)
