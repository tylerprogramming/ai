# 04 Youtube Service

A Gradio app where a `script_maker` agent and a `description_maker` agent team up in a group chat to write a YouTube script and a matching description from the type, topic, tone, length and camera style you pick.

Updated to AutoGen v0.7 (the new `autogen_agentchat` API).

## Run it

```bash
pip install -r requirements.txt
```

Put your `OPENAI_API_KEY` in a `.env` file, then:

```bash
python main.py
```
